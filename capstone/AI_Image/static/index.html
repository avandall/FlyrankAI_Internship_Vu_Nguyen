💡 Vision AI Pipeline Info

1
File Validation

Format check, size limit (10MB), content-type validation

2
Vision AI Analysis

Calls Groq API (llama-3.2-11b-vision-preview or Ollama llava) for semantic extraction: subject, tags, caption, confidence

3
Confidence Gate

Images with confidence < 0.70 are flagged and excluded from matching

4
Embedding Generation

Creates 64-dim semantic vector from caption + tags for cosine similarity search

5
DB Storage (SQLite)

Persists metadata + embedding. Survives server restarts.

🖼️ Image Library

All ingested images with AI-extracted metadata. Flagged = low confidence (<0.70).

✅ Human Review API

Approve or reject AI-suggested image matches. Builds audit trail for Top-1 Precision measurement.
