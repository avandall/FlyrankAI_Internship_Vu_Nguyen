💳 Simulate Stripe Webhook

This simulates Stripe CLI sending signed webhooks to our backend. The backend verifies the Stripe-Signature HMAC header.

🔐 HMAC Webhook Security

Stripe Webhook Signature format:
Stripe-Signature: t=162000000,v1=a1b2c3d4...

Backend Verification:
expected_sig = HMAC_SHA256(secret, "t.payload")
compare_digest(expected_sig, v1_sig)

If you send a forged signature, the backend will return HTTP 400 Bad Request and reject the event.
